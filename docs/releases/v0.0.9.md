# Selyra OS v0.0.9

Experimental release. Not ready for physical-device flashing.

Starting with v0.0.9, Mobile OS is named Selyra OS.
Previous releases retain their original names.

## Changes

- Added a central VERSION file for build versioning.
- Updated system identification to Selyra OS.
- Added memory monitoring through statusctl.
- Added CPU usage and core information.
- Added kernel, architecture and uptime reporting.
- Added powerctl for poweroff and reboot requests.
- Added authenticated PID 1 power control IPC.
- Added controlled service shutdown with SIGTERM
  and timeout-based SIGKILL escalation.
- Added kernel poweroff and reboot integration.
- Extended x86-64 and ARMv7 builds and tests.

## Testing

- Tested memory, CPU and system information.
- Tested IPC command handling and permissions.
- Tested power request authentication and rejection.
- Tested duplicate power request handling.
- Tested service shutdown state transitions.
- Tested QEMU poweroff and reboot.
- Tested forced shutdown of an unresponsive service.
- Tested cross-UID IPC rejection inside QEMU.
- Passed x86-64 and ARMv7 boot checks.
- Passed offline Galaxy S3 image validation.

## Limitations

- Selyra is still an experimental operating system.
- No graphical interface or mobile application platform.
- No verified physical phone boot.
- Galaxy S3 images are NOT FLASH READY.
- No implemented downgrade or update manager.
- No persistent user data migration mechanism.
- Google application compatibility is not implemented.
- The current shutdown tests do not prove that every
  possible orphaned process is correctly terminated.
- Security testing is incomplete for production use.

## Next

- Continue storage and configuration infrastructure.
- Design future update and rollback mechanisms.
- Prepare for graphical and mobile hardware support.
