# Mobile OS v0.0.5.2

This release introduces private directories for system
services.

## Changes

- Added /var/lib/mobile-os/system for system data.
- Added /var/lib/mobile-os/statusd for service data.
- Set directory ownership and access permissions.
- Added a filesystem permission test.

## Testing

- Existing IPC tests passed.
- System booted successfully in QEMU.
- Statusd ran as UID 1100 and GID 1100.
- Statusd could write to its own directory.
- Writing to the root-owned system directory
  was denied with EACCES.
- The normal service was restored and boot-tested.

## Limitations

- Isolation currently relies on Unix permissions.
- No filesystem namespaces or mandatory access control.
- Only write access to the two private directories
  was tested.
- The test directories exist in the temporary
  initramfs filesystem.
- Persistent storage is not implemented.

## Next

Continue developing process isolation and
filesystem security.
