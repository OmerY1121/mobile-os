# Mobile OS v0.0.5

This release adds basic peer authentication to
the local IPC system.

## Changes

- Added peer credential checks using SO_PEERCRED.
- Connections from different UIDs are rejected.
- Added cross-user authentication tests.
- Added GitHub Actions CI for automated testing.

## Testing

- Existing IPC tests passed.
- Authorized connections were accepted.
- Unauthorized connections were rejected.
- Authentication tests passed on GitHub Actions.
- System boot verified in QEMU.

## Limitations

- Programs sharing the same UID are not isolated.
- No application permission framework yet.
- Authentication is only implemented in statusd.
- No mobile hardware support.

## Next

Continue working on process isolation
and system security.
