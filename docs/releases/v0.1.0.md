# Selyra OS 0.1.0

This release is mostly about cleanup and fixes. There are no major new features.

## What changed

- Replaced the remaining Mobile OS system paths with Selyra paths.
- Added SELYRA_ environment variables. The old MOBILE_OS_ names still work.
- Fixed the IPC authorization test to work with the Codespaces sudo setup.
- Added tests for the old and new environment variables.
- Added SemVer validation for future releases.
- Added a check to catch outdated ARMv7 boot images before testing.
- Updated GitHub Actions with version checks and ARMv7 build tests.

## Version numbering

We're switching to the standard three-part SemVer format: major.minor.patch.

Some older Mobile OS releases used four-part version numbers. Those releases and their Git tags will stay as they are.

Although 0.1.0 is a minor version under SemVer, this is mainly a maintenance update. The version change also marks the move to a consistent numbering system.

## Compatibility

Existing scripts using MOBILE_OS_ environment variables should continue to work.

System paths have changed, so scripts with hardcoded Mobile OS paths may need updating.

## Current limitations

Selyra is still experimental. The Galaxy S3 image has only been tested offline and is not ready to flash. Physical device booting has not been verified.
