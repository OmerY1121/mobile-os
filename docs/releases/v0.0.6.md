# Mobile OS v0.0.6

This release focuses on service management and process isolation. Most of the changes are under the hood, but they make the system easier to test and give us a better base to build on.

`statusd` now runs inside its own PID namespace, with a small supervisor process responsible for managing its lifetime. The service manager has also been updated to clean up leftover processes, handle normal shutdowns and avoid restarting a service indefinitely when it keeps failing.

There are a few additions to the IPC interface as well. `statusctl` now supports `status`, `ping`, `uptime` and `stop`. The last command is restricted to root, while the others can be used by authorized clients.

Testing was another focus of this release. We added QEMU-based checks for booting, crashes, restarts, process cleanup and clean shutdowns. These can now be run alongside the existing IPC tests with `make test-all`.

The system is still an early x86_64 prototype. There's no graphical interface, phone hardware support or ARM64 build yet. Service management is also limited to a single service for now.

Next, I'll be working on support for multiple services, configuration and local system logging.
