# Mobile OS v0.0.4

This release improves IPC error handling.

## Changes

- Added ipc_io.h with shared IPC functions.
- Added support for partial message transfers.
- Added socket read and write timeouts.
- Improved handling of invalid requests.
- Updated the build dependencies.

## Testing

- IPC communication test passed.
- Socket permission test passed.
- Partial message test passed.
- Unknown command test passed.
- Oversized request test passed.
- Request timeout test passed.
- Connection recovery test passed.
- System boot tested in QEMU.

## Known limitations

- Clients are handled sequentially.
- No application-level authentication yet.
- Timeouts apply to individual operations,
  not the entire request.
- No general IPC permission framework.
- Only tested on x86-64.

## Next

Continue improving system security
and service management.
