# Selyra OS 0.2.0

This release adds persistent storage to Selyra.
Files stored on the data disk can now survive
system shutdowns and restarts.

## What changed

- Added ext4 storage support through VirtIO.
- Added read-only and read-write storage modes.
- Added disk validation and permission checks.
- Restricted access to /data to root.
- Added statusctl storage.
- Added filesystem synchronization and unmounting
  before shutdown.
- Added storage persistence and permission tests.
- Extended GitHub Actions with x86-64 QEMU tests.

## Compatibility

Storage is disabled by default.

Use selyra.storage=ro to enable read-only storage
or selyra.storage=rw to enable read-write storage.

Existing commands and services remain unchanged.

## Current limitations

Persistent storage has only been tested in x86-64 QEMU.
Storage encryption is not implemented yet.
Recovery after unexpected power loss has not been tested.

The Galaxy S3 image remains untested on physical
hardware and is not ready to flash.
