# Mobile OS v0.0.5.3

This release adds no_new_privs to the statusd startup process.

## Changes

- Enabled PR_SET_NO_NEW_PRIVS before executing statusd.
- Added runtime verification using PR_GET_NO_NEW_PRIVS.
- Kept the existing UID and GID separation.

## Testing

- Existing IPC tests passed.
- System booted successfully in QEMU.
- Statusd started with UID 1100 and GID 1100.
- Statusd reported no_new_privs=1.
- Local IPC initialized successfully.

## Limitations

- No privilege escalation attempt has been tested yet.
- No seccomp filters or namespace isolation.
- Only statusd uses this security configuration.
- Full application sandboxing is not implemented.

Continue process isolation in v0.0.6.
