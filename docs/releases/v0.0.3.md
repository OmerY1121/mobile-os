# Mobile OS v0.0.3

This version introduces local communication between processes.

The previous release could start and monitor a service,
but there was no way for another process to communicate
with it.

## Changes

- Added Unix domain socket support to statusd.
- Added statusctl as a small IPC client.
- Added a STATUS request and response.
- Restricted socket access using filesystem permissions.
- Removed the periodic status messages.

## Testing

Environment: GitHub Codespaces
Architecture: x86-64
Kernel: Linux 6.8.0-149-generic
Emulator: QEMU

The first compilation failed because the return
value of write() was ignored. This was corrected.

Host test:
- Started statusd as a background process.
- Connected using statusctl.
- Received "statusd: running".

QEMU test:
- Booted the system with the new statusd.
- Confirmed that the local socket was created.
- Used a temporary init test program to run statusctl.
- Received the expected response.
- IPC test passed.

The temporary init test program was removed
from the release build.

## Limitations

- Only one IPC command is implemented.
- No general service discovery.
- No application permission framework.
- Socket access currently relies on Unix permissions.
- The client is not launched by the normal init process.
- The IPC protocol needs more robust error handling.

## Next

Improve the system infrastructure before introducing
more services.
