# Mobile OS v0.0.2

This release adds basic service management to init.

Previously, init only handled early boot and then
waited indefinitely. It can now start a separate
service, detect when it exits and attempt to restart it.

## Changes

- Added statusd, a small test service.
- Added process creation using fork() and exec().
- Added service monitoring using waitpid().
- Added automatic restart after service failure.
- Limited repeated failures to prevent restart loops.

## Testing

Environment: GitHub Codespaces
Architecture: x86-64
Kernel: Linux 6.8.0-149-generic
Emulator: QEMU

Normal boot:
- Init started statusd successfully.
- Statusd reported its status every five seconds.

Failure test:
- Replaced the service executable with a test
  program that exits with code 1.
- Init detected each failure.
- The service was started three times in total.
- Restart attempts stopped after the third failure.

The original statusd executable was restored
after testing, and normal operation was verified.

## Limitations

- Only one service is managed.
- No service dependencies or configuration files.
- No inter-process communication system yet.
- No graphical interface or mobile hardware support.
- Restart limits are currently hardcoded.
