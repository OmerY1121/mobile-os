# Mobile OS v0.0.1

The first working build of Mobile OS.

This version uses the Linux kernel with a small
init process written in C. The goal was to get
our own userspace program running at boot.

## Implementation

The init program checks its PID, attempts to
mount /proc, prints startup messages and waits.

It is statically linked and packaged into a
minimal initramfs.

## Testing

Environment: GitHub Codespaces
Architecture: x86-64
Kernel: Linux 6.8.0-149-generic
Emulator: QEMU (TCG)

The first boot failed because QEMU could not
read the kernel image.

Copying the kernel into the build directory
resolved the permission issue.

The second attempt booted successfully.
The kernel started our init process as PID 1.

## Known limitations

There is no service manager, graphical interface,
networking or mobile hardware support.

The /proc mount has not been independently tested.

## Next steps

v0.0.2 will introduce basic service management,
