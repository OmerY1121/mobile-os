# Mobile OS v0.0.5.5

This release restricts process information visible to statusd.

## Changes

- Added a separate /proc mount for statusd.
- Enabled hidepid=2 on the service's /proc.
- Kept the existing mount namespace and UID isolation.
- Added proccheck.c to test process visibility.

## Testing

- Existing IPC tests passed.
- System booted successfully in QEMU.
- Statusd could read /proc/self/status.
- Access to /proc/1/status was denied.
- Normal service operation was verified.

## Limitations

- This is not a separate PID namespace.
- Processes sharing the same UID may still be visible.
- hidepid does not provide complete process isolation.
- The /proc test is currently run manually in QEMU.

## Next

Continue process isolation in v0.0.6.
