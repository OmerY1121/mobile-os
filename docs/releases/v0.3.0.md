# Selyra OS 0.3.0

This release adds system configuration and
runtime service management.

## What changed

- Added configd and configctl.
- Added persistent system settings.
- Added configuration validation and recovery.
- Added servicectl for runtime service management.
- Added persistent service startup policies.
- Added configurable hostname and log size limits.
- Added configuration IPC authentication.
- Fixed missing build dependencies.
- Extended automated tests and CI coverage.

## Compatibility

Settings are stored under /data/config when
persistent storage is enabled.

Hostname and log size changes take effect
on the next boot.

## Current limitations

Runtime service control is limited to logd
and statusd.

Persistent storage has only been tested in QEMU.
Physical mobile hardware remains untested.

The Galaxy S3 image is not ready to flash.
