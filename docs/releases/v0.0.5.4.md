# Mobile OS v0.0.5.4

This release adds a separate mount namespace for statusd.

## Changes

- Added mount namespace creation using unshare().
- Disabled shared mount propagation.
- Added a private tmpfs at /tmp for statusd.
- Limited the tmpfs to 4 MB.
- Mounted it with nosuid, nodev and noexec.
- Added a mount isolation test.

## Testing

- Existing IPC tests passed.
- System booted in QEMU.
- Statusd started with reduced privileges.
- Verified that /tmp uses tmpfs.
- Verified that the original /tmp marker is hidden.
- Verified that statusd can write to its private /tmp.
- Restored the normal service after testing.

## Limitations

- Only /tmp has a separate mount.
- Other filesystem paths remain visible.
- Parent namespace isolation has not been
  independently tested.
- No full filesystem sandbox yet.
- No persistent storage or ARM64 support.
