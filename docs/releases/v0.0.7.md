# Mobile OS v0.0.7

Mobile OS v0.0.7

This release adds ARMv7 support and starts the work needed to boot Mobile OS on real hardware. The Samsung Galaxy S III (GT-I9300) is the first device we’re targeting.

Changes

* Added cross-compilation scripts for the ARMv7 versions of init, statusd and statusctl.
* Added ARM IPC tests using QEMU user-mode emulation.
* Booted Mobile OS in QEMU using a 32-bit ARM Linux kernel.
* Added automated ARM boot checks alongside the existing x86_64 tests.
* Added scripts for preparing a Galaxy S3 initramfs containing our system binaries.
* Added support for building an experimental Android boot image using the postmarketOS Exynos4 kernel and the Galaxy S3 device tree.
* Added offline checks for the boot image header, kernel, ramdisk, load addresses and image size.
* Added a script to package the Galaxy S3 test files together.

Testing

* ARMv7 binaries compiled and ran under emulation.
* status, ping and uptime passed the ARM IPC tests.
* Mobile OS booted in ARM QEMU, with its init process running as PID 1.
* Verified that the existing service isolation and IPC functionality also worked on ARM.
* Checked the Galaxy S3 device metadata against the available postmarketOS configuration.
* Built an experimental boot image measuring 6,832,128 bytes, below the 8 MiB BOOT partition limit.
* Verified that the boot image contained the expected kernel, device tree and initramfs.

Fixes

* Fixed an initramfs contents check that initially expected a different path format in the CPIO archive.
* Worked around a missing gki Python module in the packaged mkbootimg tool by using a separate version of the boot image builder.
* Re-ran the image checks after these changes.

Limitations

* The Galaxy S3 boot image has not been tested on a physical device.
* Passing the offline checks does not guarantee that the phone will boot.
* Display, touchscreen, USB debugging and other phone hardware functions are not implemented or verified.
* The boot image builder workaround still needs to be made part of a reproducible setup from a fresh checkout.
* The GitHub Release contains source archives, not a verified flashable image.
* ARM64 is not supported yet.

Next

Work on local system logging, boot diagnostics and managing multiple services. Hardware testing on the Galaxy S3 will continue once the device and recovery setup are ready.
