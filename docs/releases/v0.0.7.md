# Mobile OS v0.0.7

This release brings the first ARMv7 builds of Mobile OS.

The init system, statusd and statusctl can now be compiled for 32-bit ARM. The existing IPC commands have been tested under ARM emulation, and the system has booted in QEMU with an ARM Linux kernel.

I've also started working on hardware support for the Samsung Galaxy S III (GT-I9300). There's now a set of scripts for preparing an initramfs, combining it with an Exynos4 kernel and checking the resulting Android boot image.

The generated image passes the offline format, content and size checks. It hasn't been tested on a physical Galaxy S3 yet, so it should not be flashed.

The core system is still device-independent. The Galaxy S3 scripts are an initial hardware target, not a separate version of Mobile OS.

Next up are better boot diagnostics, system logging and further work on the service infrastructure.
