# Mobile OS v0.0.5.1

This release introduces basic service privilege separation.

Previously, statusd ran with root privileges.
It now runs under a dedicated UID and GID.

## Changes

- Assigned UID 1100 and GID 1100 to statusd.
- Added privilege dropping before executing the service.
- Removed supplementary groups from the service process.
- Restricted access to /run/mobile-os.

## Testing

- Existing IPC tests passed.
- System booted successfully in QEMU.
- Init reported UID 1100 and GID 1100 before
  executing statusd.
- Statusd started and initialized its IPC socket.

## Limitations

- Only statusd has a dedicated service identity.
- No filesystem sandbox or namespace isolation.
- Service credentials are hardcoded.
- Full application isolation is not implemented.
- Cross-UID IPC policies need further development.

## Next

Introduce filesystem access restrictions
and test process isolation.
