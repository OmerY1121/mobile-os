# Mobile OS v0.0.3.1

This release adds a build system and automated IPC tests.

## Changes

- Added a Makefile for building the system.
- Added make run for booting in QEMU.
- Added make clean for removing build artifacts.
- Added automated IPC tests.
- Added a test for Unix socket permissions.

## Testing

- Verified IPC communication between statusctl and statusd.
- Checked Unix socket permissions.

## Limitations

- Only basic IPC functionality is tested.
- No automated QEMU boot test yet.
- IPC error handling still needs improvement.

## Next

Continue system and security improvements in v0.0.4.
